# Lily Game

A simple, interactive clicker game about growing a lily, accessible online at [lily-game.vercel.app](https://lily-game.vercel.app/).

This project was developed entirely using standard web technologies to create a lightweight, responsive browser game. It features a persistent progression system by utilizing browser local storage, ensuring that the player's progress in growing their lily is saved across sessions.

## Features

* **Clicker Mechanics:** Core gameplay loop centered around interaction to progress through the different growth stages of the plant.
* **Persistent State:** Utilizes the Web Storage API (Local Storage) to save game data, allowing users to close the browser and resume their progress later.
* **Asset Integration:** Incorporates custom image assets (`1.png` to `5.png`) to visually represent the various stages of the lily's growth cycle.
* **Zero Dependencies:** Built entirely without external libraries or frameworks.

## Tech Stack

This project is built purely with vanilla web technologies:

* **HTML5:** For the core structure and layout of the game.
* **CSS3:** For styling, responsive design, and visual presentation.
* **JavaScript (Vanilla):** For all game logic, interaction handling, DOM manipulation, and local storage management.

## About the Project

This repository serves as a practical demonstration of handling core web development concepts such as DOM manipulation, event listeners, state management, and the Local Storage API using pure JavaScript.
